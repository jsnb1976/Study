## Parameter Architecture  (`charlemagne_params.scad`)

All dimensions are **in millimetres at reference scale SF=1.0 (BERYL vessel)**.
`p(constant, sf)` = `constant * sf` — linear scaling for all spatial params.
Explode offsets (`EX_*`) are raw mm constants, multiplied by SF and ef in calls.
`hub_power(sf)` = `round(7500 * pow(sf, 3))` — watts, cubic power scaling.

### Physical constants
| Constant     | Value (mm) | Meaning                                |
|--------------|-----------|----------------------------------------|
| `HULL_H`     | 1200      | hull height (floor to roof)            |
| `HULL_L`     | 4200      | hull total length                      |
| `HULL_W`     | 2200      | hull width at widest                   |
| `GND_CLR`    | 350       | ground clearance (bottom of hull to Z=0)|
| `BELLY_T`    | 60        | belly pan plate thickness              |
| `LEG_REACH`  | 1200      | radial distance from centre to leg pivot |
| `CMBC_OD`    | 500       | CMBC vault outer footprint dimension   |
| `DOME_BASE_R`| 550       | ALON dome base radius (fits hull aperture)|
| `DOME_H`     | 480       | ALON dome height                       |
| `DOME_FLANGE_T`| 28      | dome mounting flange thickness         |
| `AAJ_BODY_L` | 340       | AAJ body length                        |
| `AAJ_FLANGE_D`| 120      | AAJ-to-hull flange diameter            |
| `HUB_R`      | 280       | hub motor+tyre assembly radius         |
| `HUB_W`      | 180       | hub motor width                        |
| `HUB_AXLE_D` | 42        | hub axle diameter (matches leg foot)   |
| `LEG_L`      | 900       | leg total length hip-to-foot           |
| `LEG_UPPER_L`| 520       | upper arm length                       |
| `LEG_LOWER_L`| 380       | lower arm length                       |
| `SENSOR_W`   | 320       | sensor array housing width             |
| `SENSOR_H`   | 240       | sensor array housing height            |
| `SENSOR_D`   | 180       | sensor array housing depth             |

### Explode offsets (raw mm, scaled ×SF×ef at call site)
| Constant   | Value | Component moved                  |
|------------|-------|----------------------------------|
| `EX_DOME`  | 420   | ALON dome (upward)               |
| `EX_AAJ`   | 320   | AAJ joints (outward ±X)          |
| `EX_VAULT` | 320   | CMBC vault(s) (downward)         |
| `EX_LEG`   | 380   | Legs (outward radial)            |
| `EX_MOTOR` | 220   | Hub motors (extra outward)       |
| `EX_NOSE`  | 520   | Nose sensor array (forward +X)   |
| `EX_PON`   | 220   | Belly pan (downward)             |

### Leg angle arrays

### Key derived interface relationships (all at ef=0)
- Dome base sits on hull top at Z = `gc + hh`; dome base radius = `DOME_BASE_R*sf`
- AAJ hull socket centres at Z = `gc + hh*0.4`, X = ±`hl*0.28`
- Belly pan top face at Z = `gc` (ground clearance plane)
- Belly pan centre at Z = `gc - BELLY_T*sf/2`
- Leg pivot at (`LEG_REACH*sf`, 0, `gc`); foot at ground (Z≈0)
- Hub motor axle at Z ≈ `HUB_R*sf` (tyre radius from ground)
- CMBC vault centre at Z = `gc` (half-embedded in belly region)

## Component module signatures & geometry intent

### `charlemagne_hull(sf=1.0)`
- Main body: `minkowski(cube + sphere)` rounded box
  `[HULL_L*sf, HULL_W*sf, HULL_H*sf]` centred at origin
- Nose: ellipsoidal fore extension, chamfered
- Stern: squared stern with tow-hitch recess
- Side skirts: lower swept flange `BELLY_T*sf` deep
- Window band: `difference()` — horizontal strip subtract, re-add window frames
- Door panels: paired recesses port/starboard
- Vent louvres: small subtract array on each flank
- Mounting rail: underside subtract slot `CMBC_OD*sf` × `BELLY_T*sf*0.5` × `HULL_L*sf*0.6`
- Dome aperture: circular cutout on roof radius = `DOME_BASE_R*sf`
- AAJ sockets: recessed cylinders at ±`hl*0.28`, Z=`gc+hh*0.4` (radius = `AAJ_FLANGE_D*sf/2`)

### `alon_dome(sf=1.0)`
- Outer shell: `intersection(sphere(DOME_BASE_R*sf*1.05+DOME_H*sf), half-space above Z=0)`
- Inner shell: `difference(outer, sphere(DOME_BASE_R*sf*1.05+DOME_H*sf - 18*sf))`
- Mounting flange: cylinder `r=DOME_BASE_R*sf+DOME_FLANGE_T*sf, h=DOME_FLANGE_T*sf`
- Frame ribs: 8 meridional rib strips, 3 latitudinal bands
- Origin at base (Z=0 is bottom of flange)

### `charlemagne_aaj(sf=1.0, expanded=false)`
- Housing cylinder: `r=AAJ_FLANGE_D*sf/2+20*sf, h=AAJ_BODY_L*sf`
- Internal bore: `r=AAJ_FLANGE_D*sf/2`
- Pin: `sphere(r=15*sf)` at joint pivot mid-point
- Upper flange plate: `cylinder(r=AAJ_FLANGE_D*sf/2+10*sf, h=DOME_FLANGE_T*sf)`
- Lower flange plate: matching, rotated 30° for bolt pattern stagger
- If `expanded`: translate pin gap by `40*sf` to show articulation
- Bolt holes: 6× M12 pattern on both flanges

### `cmbc_vault(sf=1.0)`
- Outer case: rounded cuboid `[CMBC_OD*sf, CMBC_OD*sf*0.85, CMBC_OD*sf*0.55]`
- Cooling fins: 12× thin plates on each long face, spaced `CMBC_OD*sf/14`
- Battery cell array: subtract grid of 18650-form cylinders `r=9*sf, h=70*sf` (6×N array)
- Controller bay: forward section, vent grille pattern
- Connector ports: 4× recessed cylinders on rear face
- Mounting lugs: 4× bosses with M10 through-holes on base

### `hub_motor_assembly(sf=1.0)`
- Tyre: `rotate_extrude()` of D-profile with `r_outer=HUB_R*sf, w=HUB_W*sf`
- Rim: thin inner cylinder, 5-spoke pattern via subtract
- Stator housing: `cylinder(r=HUB_R*sf*0.55, h=HUB_W*sf*0.7)` at centre
- Axle stub: `cylinder(r=HUB_AXLE_D*sf/2, h=20*sf)` protruding each side
- Brake disc: thin annular ring `r=HUB_R*sf*0.7` on inboard face
- Caliper: small box subtract-slot on disc, inboard side

### `charlemagne_leg(sf=1.0, angle_deg=12)`
- Hip joint: sphere `r=35*sf` at origin (pivot)
- Upper arm: rotate `[angle_deg,0,0]` cylinder `r=22*sf, h=LEG_UPPER_L*sf`
- Knee joint: sphere `r=28*sf` at end of upper arm
- Lower arm: continues with `r=18*sf, h=LEG_LOWER_L*sf`
- Foot/axle hub: cylinder `r=HUB_AXLE_D*sf/2+4*sf, h=HUB_W*sf+8*sf` centred
- Structural rib: triangular gusset box connecting upper+lower arms
- All arms use `minkowski(cylinder, sphere(3*sf))` for chamfered edges

### `sensor_array(sf=1.0)`
- Main housing: `minkowski(cube, sphere(8*sf))` rounded box
  `[SENSOR_D*sf, SENSOR_W*sf, SENSOR_H*sf]`
- LIDAR drum: cylinder `r=55*sf, h=50*sf` protruding from top
- Forward cameras: 2× cylinders `r=22*sf` recessed left/right in front face
- Side radar domes: 2× `sphere(30*sf)` flush-mounted on flanks
- Comm antenna post: thin cylinder `r=6*sf, h=90*sf` on top rear
- Cable conduit: `cylinder(r=18*sf)` at base, connects to hull
- Mounting foot: flange plate with 4× M8 bolt holes

### `belly_pan(sf=1.0)`
- Base plate: `cube([HULL_L*sf*0.95, HULL_W*sf*0.92, BELLY_T*sf])` centred
- Longitudinal ribs: 5× `cube([HULL_L*sf*0.90, 12*sf, BELLY_T*sf*1.8])` along X-axis
- Transverse ribs: 8× ribs along Y-axis, notched at rib intersections
- Drain slots: 4× elongated cutouts, `[80*sf, 18*sf, BELLY_T*sf]`
- CMBC mounting rail: `[CMBC_OD*sf*0.9, CMBC_OD*sf*0.9, 20*sf]` boss with bolt pattern
- Belly skid strips: 3× `cube([HULL_L*sf*0.7, 25*sf, 8*sf])` proud of bottom face

## Vessel file template (per-vessel logic)

Each vessel file begins with a descriptive header block, then:

```openscad
// ===========================================================
// CSM Charlemagne Fleet V2 — [VESSEL NAME]
// Scale Factor: SF=[value]  |  Explode Factor: ef=[value]
// Legs: [N]  |  AAJ joints: [N]  |  CMBC vaults: [N]
// Hub motor power (per wheel): hub_power(SF) W
// ===========================================================

use <../lib/charlemagne_params.scad>
use <../lib/components/hull.scad>
use <../lib/components/alon_dome.scad>
use <../lib/components/aaj.scad>
use <../lib/components/cmbc_vault.scad>
use <../lib/components/hub_motor.scad>
use <../lib/components/leg.scad>
use <../lib/components/sensor_array.scad>
use <../lib/components/belly_pan.scad>

// ── Vessel parameters ─────────────────────────────────────
SF  = <sf_value>;
ef  = <ef_value>;

// ── Derived layout variables ──────────────────────────────
gc  = p(GND_CLR,  SF);   // ground clearance
hh  = p(HULL_H,   SF);   // hull height
hl  = p(HULL_L,   SF);   // hull length

// ── Hull ──────────────────────────────────────────────────
translate([0, 0, gc + hh/2])
  charlemagne_hull(sf=SF);

// ── ALON Dome ─────────────────────────────────────────────
translate([0, 0, gc + hh + ef*EX_DOME*SF])
  alon_dome(sf=SF);

// ── AAJ Joints (2 or 3) ───────────────────────────────────
for (xs = <[1,-1] or [1,0,-1] for RHODONITE>)
  translate([xs*hl*0.28 + xs*ef*EX_AAJ*SF, 0, gc + hh*0.4])
    charlemagne_aaj(sf=SF, expanded=(ef > 0.5));

// ── CMBC Vault(s) ─────────────────────────────────────────
// Standard (1 vault):
translate([0, 0, gc - ef*EX_VAULT*SF])
  cmbc_vault(sf=SF);
// RHODONITE (4 vaults in 2×2 grid at ±CMBC_OD*sf*0.55 X/Y):
for (vx=[-1,1], vy=[-1,1])
  translate([vx*p(CMBC_OD,SF)*0.55, vy*p(CMBC_OD,SF)*0.55, gc - ef*EX_VAULT*SF])
    cmbc_vault(sf=SF);

// ── Legs + Hub Motors ─────────────────────────────────────
for (ang = <LEG_ANG_N>)
  rotate([0, 0, ang]) {
    translate([p(LEG_REACH,SF) + ef*EX_LEG*SF, 0, gc])
      charlemagne_leg(sf=SF, angle_deg=12);
    translate([p(LEG_REACH,SF) + ef*(EX_LEG+EX_MOTOR)*SF, 0, p(HUB_R,SF)])
      hub_motor_assembly(sf=SF);
  }

// ── Nose Sensor Array ─────────────────────────────────────
translate([hl/2 + ef*EX_NOSE*SF, 0, gc + hh*0.3])
  sensor_array(sf=SF);

// ── Belly Pan ─────────────────────────────────────────────
translate([0, 0, gc - p(BELLY_T,SF)/2 - ef*EX_PON*SF])
  belly_pan(sf=SF);
```

Note: The template in the original spec uses `p(BELLY_T,SF)` at hub motor Z position.  
I'm using `p(HUB_R,SF)` which is more physically correct (motor centre at wheel radius height).  
The belly pan translate matches spec exactly.

## Shared-fit notes
- All component modules accept `sf` and scale via `p()` — single scaling source of truth
- Hull aperture for dome (`DOME_BASE_R*sf`) exactly matches dome flange base radius
- AAJ flange diameter (`AAJ_FLANGE_D*sf`) exactly matches hull socket inner diameter
- Leg foot hub diameter (`HUB_AXLE_D*sf+8*sf`) matches hub motor axle sleeve
- Belly pan plan dimensions `HULL_L*sf × HULL_W*sf` match hull underside footprint
- CMBC vault base footprint `CMBC_OD*sf × CMBC_OD*sf*0.85` fits within belly rail slot
